# VANILLA WINDOW

VANILLA WINDOW is a rendering module for VANILLA

This repository contains the different released versions of VANILLA WINDOW. Each version is kept separately so that previous releases remain available and can be used independently.

## Versions

Available versions are organized by release:

```text
VANILLA WINDOW/
├── v1.0.0/
└── ...
```

Each version contains its own source code, headers, build instructions, and required files.

## Platform

VANILLA WINDOW is currently developed for Linux.
